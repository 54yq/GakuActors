# GakuActors Windows x64 安装

这是开发测试版。请先退出游戏和 GakuActors，再双击 `Install.cmd`，输入包含 `gakumas.exe` 的游戏目录。安装程序将插件和桌面程序安装到各自目录，并备份被覆盖的文件。未检测到 `version.dll` 时安装随包的 GakuLoader；如果已有其他 `version.dll` 且没有 GakuLoader 目录，安装会停止以避免覆盖。已安装 GakuLoader 时保留现有版本，请确认兼容。

安装后使用桌面快捷方式，或从游戏根目录的 `GakuActors` 文件夹启动桌面程序。游戏插件位于 `GakuLoader/plugins`。移动整个游戏文件夹后，在新的 `GakuActors` 文件夹用 PowerShell 运行 `./Repair-Shortcuts.ps1 -Desktop` 来重建快捷方式。

安装包提供 Python 运行时、乐库解码器及资源库导出工具，不需要单独安装 Python。Windows 需有 [Microsoft Visual C++ 2015–2022 x64 运行库](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist) 和 .NET Framework 4.7.2 或更新版本；如有运行库缺失或版本过旧，可运行包中 `dependencies/vc_redist.x64.exe` 并按照 Microsoft 提示安装。游戏及其资源、资源库缓存、用户配置不包含在安装包中。资源库数据默认放在 `%LOCALAPPDATA%/GakuActors/ResourceLibrary`。

若使用 Motion 插件，保留已有 Loader 和 Motion 文件。兼容性与具体游戏版本需要实机验证；安装前备份原有模组。发布包不会清除已有游戏配置和缓存。安装过程建立的备份位于 `GakuLoader/Backups/GakuActors`，其中 `restore.json` 记录了操作路径。

项目与第三方许可证、来源见 `licenses/` 及各组件目录。安装包中的程序不包含游戏模型、音频或其他游戏资产。
