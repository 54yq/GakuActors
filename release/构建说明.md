# Windows x64 发布构建说明

此目录是发布候选的组装依据。请从与二进制对应的干净源码检出构建；根目录为 GakuActors，`resource-backend/` 为资源库后端源码。游戏数据、用户缓存、日志、虚拟环境和第三方工具的工作副本不属于源码。

1. 按项目 README 使用 MSVC、Windows SDK、CMake、Conan 和 `camera-core/hosted/conanfile.py` 构建集成插件，保存 `GakuActors.dll` 与 GPL 许可证。使用锁定的 Cargo 依赖和 `build-desktop.ps1` 构建桌面程序，并收集 Cargo 依赖许可。
2. 从 Python 官方获取 Windows x64 嵌入式 Python 3.13.17，按 `requirements-windows.txt` 在隔离环境准备 x64 wheel，将模块和 dist-info 放入运行时 `Lib/site-packages`。`python313._pth` 应列出 `python313.zip`、`.` 和 `Lib/site-packages`。不要复制开发机 `.venv` 或其绝对路径。验证 UnityPy、NumPy、Pillow 和 PyCryptodome 导入及后端测试。
3. 将 `resource-backend` 的 `app.py`、`catalog.py`、`downloads.py`、`exporters.py` 和 `web/` 作为 `ResourceBackend` 安装内容。对 vgmstream r2117 源码应用 `vgmstream-disable-txtp.patch` 后使用 CMake 构建 CLI，设置 `USE_MPEG=OFF`、`USE_VORBIS=OFF`、`USE_FFMPEG=OFF`、`USE_G7221=OFF`、`USE_G719=OFF`、`USE_ATRAC9=OFF`、`USE_CELT=OFF`、`USE_SPEEX=OFF`，并保留其 `COPYING`。按照第三方来源记录准备转换工具及许可。`GakumasModelFbx.cs` 使用 AssetStudioMod API 另行构建，详见后端 `Build-Exporter.ps1`；不要包含游戏文件或用户资源。
4. 在候选目录创建 `payload/GakuLoader/plugins`、`payload/GakuActors`、`loader/version.dll` 和 `dependencies`，按 `安装说明.md` 组装，写入 `game-root.txt` 内容 `..` 及 `resource-backend.txt` 内容 `ResourceBackend`。附带本项目、Python、Cargo、Conan 及各外部工具的许可证、源码来源和精确版本。用官方哈希和签名核对下载文件。
5. 在不含游戏和用户数据的模拟目录验证全新安装、现有 Loader 保留、升级备份、失败回退、移动目录后的路径和快捷方式、后端及乐库。另在兼容游戏与 Loader 的真实环境进行实机测试，然后才考虑公开发布。

`第三方来源.md` 提供候选使用的上游版本。个别组件有额外再分发条件，必须在发行前核实；不能将本地第三方二进制存在这一事实视为再分发授权。
