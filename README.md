# GakuActors 场景资源管理器

GakuActors 是一个面向《学园偶像大师》的 **GakuLoader 插件**。它提供独立的 Windows 窗口，帮助你在拍摄或 Live 场景中管理人物、场景节点和道具：可以读取游戏中的人物与服装信息，保存头身组合，将新人物加入场景，并调整其位置与朝向。

人物、场景和道具管理不要求安装动作插件；如果还想播放外部动作，可以另外安装 [GakuMotion](https://github.com/crested-ezios/GakuMotion)。GakuActors 不会自动给新人物绑定或复制动作，需要在动作插件中操作。

> **当前状态：`0.5.0-native-test` 开发测试版。** 不同游戏版本、人物资源和插件组合可能表现不同。新版窗口、部分人物组合、资源控制和 360° 转向仍需要更多游戏内验证。

## 功能一览

| 页面 | 可以做什么 |
| --- | --- |
| 人物管理 | 读取和搜索人物目录，选择已有预设，或组合身体、脸部和头发并保存为自定义预设；将人物加入当前场景，控制其位置和朝向。 |
| 场景管理 | 扫描场景资源，查看节点并切换允许操作的节点显隐；设置相机纯色背景；为下次摄影背景载入选择舞台。 |
| 道具管理 | 扫描当前场景中可识别的道具，选择道具并切换显隐。 |
| 模型预览图 | 人物预设与新建页分别展示身体、头部的系统 icon，优先读取校验后的 PNG 预缓存。支持按游戏清单批量预缓存并补下载缺失的官方图片。 |
| 乐库 | 独立入口读取游戏资源清单，搜索通用与 Live 版本，按需下载并导出 WAV。 |
| 自由视角 | 在本工具中开关相机，屏蔽相机快捷键对应的游戏输入；相机功能已编入本插件。 |

插件只在识别到受支持的拍摄或 Live 场景后启用相关操作，不会在游戏主页自动扫描目录或创建人物。项目本身不包含游戏模型、服装或贴图。

自由视角的操作入口在本工具；相机实现移植自 Localify 并编入 `GakuActors.dll`，不需要安装原版 Localify。W / A / S / D 移动，空格 / Ctrl 升降，方向键转向，Q / E 调整视野，R 重置，F 切换自由、跟随和第一人称模式，V 切换对应子模式；再次点击按钮关闭。插件拦截对应游戏窗口消息及常见 Unity 输入查询，其他输入路径仍需游戏内验证。配套 Motion 会在开启时释放相机，关闭后交还；不改变资源显隐交接状态。接口校验或快捷键保护失败时自由视角不会保持启用。整合版目前尚待游戏内验证。

场景人物的位置可在旧界面拖动时即时提交，点击重置后保持面板展开；独立窗口坐标编辑也会即时提交。Motion 正在播放时，当前版本暂不允许修改人物位置。

## 安装

### 准备工作

- Windows 64 位系统，以及已安装的《学园偶像大师》。
- 安装并启用 [GakuLoader](https://github.com/Gaku-Mod-Tools/GakuLoader)，具体安装方法请参照该项目的文档。
- 准备同一版本的 `GakuActors.dll` 和 `GakuActors.Desktop.exe`。前者负责游戏内操作，后者是独立窗口，**两者都需要**。
- 自由视角已编入 `GakuActors.dll`。若此前装过分离版 `GakuActorsCameraCore.dll`，升级时应先停用或移走旧文件，避免重复注册。

如项目提供了可用发布包，可从 [Releases](https://github.com/54yq/GakuActors/releases) 获取；如果暂时没有包含这两个文件的发布包，请按下方[从源码构建](#从源码构建)自行生成。仅下载 GitHub 的 Source code 压缩包不会得到编译好的插件。

### 放置文件

1. 退出游戏。
2. 按 GakuLoader 的说明安装好加载器。
3. 将同一版本的 GakuActors 文件放到 `GakuLoader/plugins/`：

```text
<游戏根目录>/
├── gakumas.exe
├── version.dll                         # GakuLoader
└── GakuLoader/
    ├── plugins/
    │   ├── GakuActors.dll              # 游戏插件
    │   └── GakuActors.Desktop.exe      # 独立管理窗口
    ├── Configs/gakuactors/             # 人物预设等配置
    └── Logs/gakuloader.log             # 加载器及插件日志
```

安装包中如果附带许可证和第三方声明文件，也请一并保留。升级时先退出游戏，同时更新这两个程序文件；想保留自定义预设时，不要删除 `Configs/gakuactors/`。

## 快速开始

1. 启动游戏。可在进入场景前打开管理窗口并编辑已保存的预设。
2. 打开 GakuLoader 控制面板，找到 **GakuActors · 场景资源管理**。默认可按 **Ctrl+J** 唤出加载器面板；如果快捷键已被修改，请使用加载器中的实际设置。
3. 点击 **打开独立资源窗口**。独立窗口需要由插件启动，请不要单独双击 EXE 使用。
4. 在左侧选择 **人物管理**、**场景管理**或**道具管理**，根据下方步骤操作。窗口底部会显示连接状态和操作结果。

如需回到原来的加载器内界面，可以在 GakuActors 面板中选择 **旧版界面**。关闭独立窗口不会关闭游戏。

场景外可编辑已保存的预设；尚未读取过的人物目录与部分模型预览需要先在支持的拍摄或 Live 场景读取。创建人物、扫描和修改场景资源等操作仅在对应场景就绪后可用。

## 乐库

在 GakuLoader 的 GakuActors 插件面板点击 **打开乐库**。乐库使用独立窗口，与人物、场景和道具管理分开；打开后自动读取本地清单，可按曲名或资源名搜索，选择版本并导出 WAV。本机翻译表未匹配到的歌曲显示资源标识。未缓存条目在点击导出时从游戏资源服务器下载，按清单大小和 MD5 校验后保存在 `GakuLoader/Cache/gakuactors/music`，不会写入游戏的 Octo 缓存。下载或校验失败会提示错误，不导出不完整文件。

选择歌曲后点击 **试听**，可暂停、继续、停止或拖动试听进度；觉得合适后点击 **导出选中歌曲**。首次试听音量为 100%，调整后会保存在 `GakuLoader/Configs/gakuactors/music-player.json`，下次打开恢复。该音量只控制乐库试听，不改变游戏或系统音量。未缓存的音频在试听时也会先下载。

本测试版使用本机 Python 和 PyCryptodome。程序优先查找用户目录下的 Anaconda Python，其次查找 PATH 中安装了 PyCryptodome 的 Python。通用音频使用随附的 vgmstream 解码；Live 版本使用与窗口一起安装的 UnityPy 依赖目录 `GakuActors.Desktop.deps`。通用版本只支持单 HCA 音轨 AWB；Live 版本支持单音频的 Unity 资源包，当前版本使用 Unity 6000.0.77f1 作为解析回退版本。其他格式会报告错误，导出不会覆盖已有文件。乐库本身不会改变游戏播放。

## 人物管理

### 读取目录并加入人物

1. 在人物页打开 **资源设置**，点击 **读取人物目录**，等待目录读取完成。
2. 在左栏搜索或选择人物，在中栏的造型图库选择预设，右栏确认身体与头部的系统预览图。
3. 在 **资源设置**中点击 **启用人物加载**。如果正在使用动作插件播放动作，请先停止播放。
4. 在右栏 **放置位置**中选择参考人物位置，点击 **加入场景**。按钮下方显示尚未满足的条件。
5. 新人物创建成功后会出现在参考人物加入时的位置，因此最初可能与参考人物重叠。切换到左侧的 **当前场景人物**，选择标有 **本插件新增** 的人物，再调整站位。

加入操作需要等待游戏完成原生模型构建；具体角色和部件是否可用取决于游戏资源与当前版本。目录中出现名称并不等于对应模型一定已下载或能够成功加载。

### 新建和编辑预设

1. 先在人物目录中选择一个人物分类，然后点击 **新建预设**。
2. 在新建页的 **身体服装**和 **头部组合**图库各选一项，查看系统真实 icon；右栏持续显示当前选择，点击图片可以放大。图标缺失时会显示原因。
3. 输入预设名称，也可留空使用模型名称自动命名。如需选择其他人物分类的模型，打开 **跨人物部件**；还可切换 **原始部件组合**分别选择身体、脸部和头发。
4. 点击 **保存预设**，等待插件确认写入成功。随后自动返回该人物的预设列表并选中新预设。点击 **返回预设列表**可取消编辑。

选中已有预设后可点击 **编辑预设**进入同一图标选择器；从内置预设编辑时会另存为自定义预设。只有自定义预设可以删除，删除后可点击 **撤销删除**恢复。删除预设不会移除场景中已经加入的人物。

### 编辑当前人物模型（MVP）

**暂时停用。** 实机测试中原生更新改变了人物实例或管理器索引，人物随后不可见，原恢复路径无法确认目标。应用与恢复均在原生接口入口处被拒绝；重新进入场景可能恢复游戏人物，但尚未验证，可能重置临时布置。不得重新启用，直到目标实例生命周期和恢复方案经过实机验证。

加载器内的 **Live 入场前换装** 是只读研究界面：打开游戏的 Live 服装选择页后，可自动尝试识别当前人物和服装，并按人物查看已保存的自定义预设。目前还不能选择、导入或应用换装，识别结果和游戏预加载路径均需实机验证；页面不会修改游戏数据。

### 定位、转向和移除

- 在 **当前场景人物**中选择身份已确认的人物，可编辑世界坐标 X / Y / Z，点击 **设置位置**应用。
- 点击 **重置位置**：新增人物回到加入时的位置，游戏人物回到首次调整前的位置。
- 输入 `0` 至 `360` 的角度并点击 **设置朝向**，也可以用 **左转 15° / 右转 15°**微调。
- **移除人物**只针对本插件创建且仍能确认归属的人物；操作前会要求确认。位置和朝向也适用于身份已确认的原有场景人物。
- 人物显隐需要先点击 **扫描场景资源**和 **启用资源控制**，切换到 **当前场景人物**，再选择目标人物并点击 **隐藏人物 / 显示人物**。

自定义预设名称用于辨认组合。支持该名称的 GakuMotion 版本可以在相应界面显示预设名；具体识别、动作绑定和物理表现取决于版本及人物组合。

## 场景与道具管理

1. 切换到 **场景管理**或**道具管理**，点击 **扫描场景资源**。
2. 点击 **启用资源控制**。如果提示动作插件冲突，请先参考下方兼容性说明。
3. 在左侧选择资源，查看右侧名称和状态；点击 **切换节点显隐**。受保护、不可操作或未识别到的资源无法切换。
4. 如需恢复，重新选择已隐藏的资源并切换显隐，或关闭资源控制，让插件尝试恢复它记录的状态。

场景页还提供 **背景颜色**和 **恢复相机**。摄影舞台在下拉框中选择后，需点击 **应用舞台**；选择保存在配置中，通常要等**下次摄影背景载入**才会生效。部分舞台为实验选项，且摄影舞台替换仅适用于受支持的摄影场景。道具列表仅包含当前扫描规则能识别的对象，不代表游戏中的全部道具。

## 与 GakuMotion 一起使用

GakuActors 可以独立管理场景资源；GakuMotion 负责外部动作、镜头等演出功能。想让新增人物使用动作时：

1. 在 GakuActors 中创建人物，并确认其已经出现在场景中。
2. 打开 GakuMotion，刷新或检查场景人物列表。
3. 在 GakuMotion 中选择对应人物并绑定动作；人物识别、名称显示、人数限制和动作物理效果取决于所用版本，可能需要逐项验证。

**Motion 资源控制交接（测试版）：** 使用支持 `gakumotion.visual-handoff` 的配套 GakuMotion 时，只需启用 **资源显隐**。插件会先请求 Motion 恢复并释放资源，然后自动启用显隐；等待期间可再次关闭以取消。关闭资源显隐时，GakuActors 会先尝试恢复自己修改的资源并交还控制；恢复失败时会保留控制权。

未提供交接接口的旧版 Motion 仍会被保守地阻止与本插件同时控制显隐。摄影背景载入钩子由加载器独占管理；交接时会尝试释放，若被其他插件占用，摄影舞台替换仍可能不可用。交接和具体游戏组合仍需实机验证。配套 Motion 源码改动见 [兼容补丁](compat/gakumotion-visual-handoff.patch)。

## 常见问题

**按钮是灰色的，或窗口提示未进入场景？** 先进入受支持的拍摄 / Live 场景，并等待游戏加载完成。加入人物还需要选中预设、选择参考人物并启用人物加载；部分功能在人物构建中或动作播放时不可用。

**找不到某套服装，或某个人物没有预设？** 先重新读取人物目录。部分人物可能只有单独的身体、脸部、头发资源，没有现成服装预设；可以尝试在人物分类下新建组合。目录是否完整、资源是否已下载及不同组合是否可用，取决于游戏实际数据。

**模型图标没有显示？** 图标来自游戏目录中 `GetThumbAssetName` 的原生记录。游戏内图片未加载时，窗口会尝试从本地 Octo 缓存提取，并校验资源包哈希。未缓存、匹配不唯一或解析失败时显示具体原因；可在游戏中打开对应服装页，再点击 **重试当前图片**。读取本地缓存需要与乐库相同的 Python、PyCryptodome 和 `GakuActors.Desktop.deps` 中的 UnityPy。

**加入后看不到新人物？** 新人物最初与参考人物重叠。等待构建完成后，在“当前场景人物”中选择标有“本插件新增”的人物，设置不同的世界坐标。若仍未出现，请查看窗口状态和日志，确认是否构建失败或资源不可用。

**显隐或背景控制不可用？** 先扫描场景资源并启用资源控制；受保护节点不能修改。若同时使用动作插件，请等待自动交接完成；摄影舞台的载入钩子仍可能被其他插件占用。

**如何反馈问题？** 在确认日志不包含不愿公开的内容后，提供游戏版本、GakuActors 与 GakuLoader 版本、是否安装 GakuMotion、所在场景、操作步骤，以及 `GakuLoader/Logs/gakuloader.log` 中相关的 `[GakuActors]` 日志。

普通使用默认关闭开发信息日志。需要排查时，按 [Live 诊断与日志](docs/LIVE_DIAGNOSTICS.md) 中的方法临时开启；警告和错误不受该开关影响。

## 从源码构建

需要 Windows x64、Visual Studio C++ 工具链、Windows SDK、CMake 4、Conan、Rust 和 Cargo。先按 `camera-core/hosted/conanfile.py` 生成 Conan CMake toolchain，然后在项目根目录执行：

```powershell
# 构建含相机功能的游戏插件：输出 build/GakuActors.dll
./build.ps1 -Target Runtime -ConanToolchain <Conan生成的toolchain路径>

# 构建独立窗口：输出 desktop-rust/target/release/gakuactors-desktop.exe
cargo build --release --manifest-path desktop-rust/Cargo.toml
```

若使用便携式 MSVC 或 Windows SDK，可向 `build.ps1` 传入 `-PortableVisualStudio` 和 `-WindowsSdkRoot`。安装时将 Rust 产物重命名为 `GakuActors.Desktop.exe`，与 DLL 一起放入 `GakuLoader/plugins/`。上述命令只构建，不会自动部署到游戏目录。

`-Cmake` 可指定 CMake 可执行文件，`-CmakeVisualStudio` 可指定 Visual Studio 实例。构建脚本同时将 GPL-3.0 许可证放入输出目录；发行整合版时须附带许可证和对应源码。

开发实现和历史验证记录见 [独立窗口说明](docs/NATIVE_DESKTOP.md)、[场景资源迁移记录](docs/SCENE_RESOURCE_MIGRATION.md) 和 [验证记录](docs/VALIDATION.md)；历史记录中的版本与状态不一定代表当前最新构建。
