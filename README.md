# GakuActors · 桌面资源库与游戏内场景管理

GakuActors 是面向《学园偶像大师》的 **Windows 桌面客户端**，配套提供 **GakuLoader 游戏内插件**。客户端可以独立浏览、下载和导出资源，也能在游戏关闭时通过乐库试听和导出歌曲。连接游戏内插件后，同一个客户端可管理拍摄和 Live 场景中的人物、舞台、道具和相机。

[直接下载 Windows x64 安装包](https://github.com/54yq/GakuActors/releases/download/v0.5.0-test.1/GakuActors-v0.5.0-test.1-win-x64.zip) · [发布说明与源码包](https://github.com/54yq/GakuActors/releases/tag/v0.5.0-test.1)

## 功能一览

| 功能 | 可以做什么 | 使用条件 |
| --- | --- | --- |
| **桌面资源库** | 搜索资源、检查依赖和下载体积，按需下载，导出受支持的模型（FBX）、贴图（PNG）和动作（Unity `.anim`）。 | Windows 客户端和随包后端。无需安装游戏或 GakuLoader。 |
| **乐库** | 搜索通用音频和 Live 音频，按需下载、试听并导出 WAV。 | 需要本地游戏目录和音频清单。无需启动游戏或加载插件。 |
| **人物与预设** | 浏览人物和服装，查看部件预览，组合身体、脸部和头发，保存预设并将人物加入场景。 | 首次读取游戏内人物目录和加入人物需要连接游戏内插件。 |
| **场景、舞台与道具** | 调整人物站位和朝向，切换场景节点或道具显隐，设置纯色背景，选择下次载入的摄影舞台。 | 需要运行游戏、加载插件并进入受支持的场景。 |
| **自由视角** | 控制游戏相机，切换自由、跟随和第一人称模式。 | 需要连接游戏内插件。 |

资源库的下载与导出在本地后端完成。导出结果可供外部工具使用。要把人物加入当前游戏场景，请切换到 **游戏管理**，打开 **人物与预设**。

## 安装

下载上面的 Windows x64 安装包并解压。包内提供 Python 运行时、解码器和导出工具。系统需要 Visual C++ x64 运行库和 .NET Framework 4.7.2 或更新版本。缺少 Visual C++ 运行库时，可运行包内的 `dependencies/vc_redist.x64.exe`。详见 [安装说明](release/安装说明.md)。

### 仅使用桌面资源库

将解压后的 `payload/GakuActors/` 整个文件夹放到你想使用的位置，双击其中的 `GakuActors.Desktop.exe`，点击窗口顶部的 **资源库**。首次打开时会检查在线清单，也可手动导入已有清单。更新清单和下载资源需要联网，已保存的清单可离线浏览。

资源库数据默认保存在 `%LOCALAPPDATA%/GakuActors/ResourceLibrary`。下载依赖、导出格式和后端配置见 [资源库说明](RESOURCE-LIBRARY.md)。

### 与游戏一起安装

1. 退出游戏和 GakuActors，双击解压目录中的 `Install.cmd`。
2. 选择包含 `gakumas.exe` 的游戏根目录。安装器会备份被覆盖的文件，保留已有 GakuLoader，并在没有 `version.dll` 时安装随包提供的 GakuLoader。
3. 用桌面快捷方式或游戏目录中的 `GakuActors.Desktop.exe` 打开客户端。如果之前装过分离版相机插件 `GakuActorsCameraCore.dll`，升级时先停用它，避免重复注册。

```text
<游戏根目录>/
├── gakumas.exe
├── version.dll                      # GakuLoader
├── GakuLoader/
│   ├── plugins/GakuActors.dll        # 游戏内插件
│   └── Configs/gakuactors/           # 人物预设等配置
└── GakuActors/
    ├── GakuActors.Desktop.exe
    ├── game-root.txt                 # 内容为 ..，指向游戏根目录
    ├── ResourceBackend/              # 资源库后端与导出工具
    ├── GakuActors.Vgmstream/          # 乐库解码器
    └── runtime/                      # Python 运行时
```

升级时保留 `GakuLoader/Configs/gakuactors/` 中的自定义预设。移动游戏目录后，客户端会按相对路径定位游戏。可在新的 `GakuActors` 目录用 PowerShell 运行 `./Repair-Shortcuts.ps1 -Desktop`，重建目录内和桌面的快捷方式。

## 连接游戏

1. 启动游戏，打开 GakuLoader 控制面板，找到 **GakuActors · 场景资源管理**。默认可按 **Ctrl+J** 唤出加载器面板；如果快捷键已被修改，请使用加载器中的实际设置。
2. 启动游戏根目录 `GakuActors` 文件夹中的 `GakuActors.Desktop.exe`，在 **游戏管理** 中查看插件连接状态。
3. 在左侧选择 **人物与预设**、**场景人物**、**场景管理**、**道具管理**或**舞台导入**。顶部显示连接状态，操作结果显示在窗口中。
4. 如果游戏已连接但目录读取失败，可点击 **重试目录**；需要重新连接时可点击 **手动连接**。

加载器内的模型界面和 Live 入场前换装仍保留。关闭独立窗口不会关闭游戏。

场景外可编辑已保存的预设；尚未读取过的人物目录与部分模型预览需要先在支持的拍摄或 Live 场景读取。创建人物、扫描和修改场景资源等操作仅在对应场景就绪后可用。

## 乐库

关闭游戏也可使用乐库。在桌面程序中点击 **打开乐库**，或使用乐库快捷方式。乐库会读取游戏目录中的本地清单，可按曲名或资源名搜索、选择版本并导出 WAV。本机翻译表未匹配到的歌曲显示资源标识。未缓存条目在点击导出时从游戏资源服务器下载，按清单大小和 MD5 校验后保存在 `GakuLoader/Cache/gakuactors/music`，不会写入游戏的 Octo 缓存。下载或校验失败会提示错误，不导出不完整文件。

选择歌曲和版本后点击 **播放**，可暂停、继续、停止或拖动播放进度；需要保存时点击 **导出所选歌曲**。首次试听音量为 100%，调整后会保存在 `GakuLoader/Configs/gakuactors/music-player.json`，下次打开恢复。该音量只控制乐库试听，不改变游戏或系统音量。未缓存的音频在试听时也会先下载。

发行包优先使用 `GakuActors/runtime` 中随附的 Python 及其依赖；开发环境在没有随附运行时时会查找本机的 Python 和 PyCryptodome。通用音频使用随附的 vgmstream 解码；Live 版本需要 UnityPy。通用版本只支持单 HCA 音轨 AWB；Live 版本支持单音频的 Unity 资源包，当前版本使用 Unity 6000.0.77f1 作为解析回退版本。其他格式会报告错误，导出不会覆盖已有文件。乐库本身不会改变游戏播放。

## 人物管理

### 读取目录并加入人物

1. 连接游戏后窗口会尝试读取人物目录。需要手动刷新时，在 **人物与预设**页打开 **资源设置**，点击 **读取人物目录**；游戏数据库尚未就绪时可稍后点击 **重试目录**。
2. 在左栏搜索或选择人物，在中栏的造型图库选择预设，右栏确认身体与头部的系统预览图。
3. 在 **资源设置**中点击 **启用人物加载**。如果正在使用动作插件播放动作，请先停止播放。
4. 在右栏 **加入场景**中选择参考人物，点击 **加入人物**。
5. 新人物创建成功后会出现在参考人物加入时的位置，因此最初可能与参考人物重叠。切换到左侧的 **场景人物**，选择标有 **本插件新增** 的人物，再调整站位。

加入操作需要等待游戏完成原生模型构建；具体角色和部件是否可用取决于游戏资源与当前版本。目录中出现名称并不等于对应模型一定已下载或能够成功加载。

### 新建和编辑预设

1. 先在人物目录中选择一个人物分类，然后点击 **新建预设**。
2. 在新建页的 **身体服装**和 **头部组合**图库各选一项，查看系统真实 icon；右栏持续显示当前选择，点击图片可以放大。图标缺失时会显示原因。
3. 输入预设名称，也可留空使用模型名称自动命名。如需选择其他人物分类的模型，打开 **跨人物部件**；还可切换 **原始部件组合**分别选择身体、脸部和头发。
4. 点击 **保存预设**，等待插件确认写入成功。随后自动返回该人物的预设列表并选中新预设。点击 **返回预设列表**可取消编辑。

选中已有预设后可点击 **编辑预设**进入同一图标选择器；从内置预设编辑时会另存为自定义预设。只有自定义预设可以删除，删除后可点击 **撤销删除**恢复。删除预设不会移除场景中已经加入的人物。

### 编辑当前人物模型（MVP）

**暂时停用。** 实机测试中原生更新改变了人物实例或管理器索引，人物随后不可见，原恢复路径无法确认目标。应用与恢复均在原生接口入口处被拒绝；重新进入场景可能恢复游戏人物，但尚未验证，可能重置临时布置。不得重新启用，直到目标实例生命周期和恢复方案经过实机验证。

加载器内的 **Live 入场前换装** 是只读研究界面：打开游戏的 Live 服装选择页后，可自动尝试识别当前人物和服装，并按人物查看已保存的自定义预设。目前还不能选择、导入或应用换装，识别结果和游戏预加载路径均需实机验证；页面不会修改游戏数据。

### 定位、转向和移除

- 在 **场景人物**中选择身份已确认的人物，使用 X / Y / Z 滑块调整世界坐标。选中滑块后可用方向键以 0.01 米微调。使用 GakuMotion 播放动作时，请先停止播放再调整人物位置。
- 点击 **重置位置**：新增人物回到加入时的位置，游戏人物回到首次调整前的位置。
- 使用 `0` 至 `360` 度的朝向滑块转向，或点击 **重置朝向**。
- **移除新增人物**只针对本插件创建且仍能确认归属的人物；操作前会要求确认。位置和朝向也适用于身份已确认的原有场景人物。
- 资源控制就绪后，可选择目标并点击 **人物模型显隐**。Live 场景中的暂停按钮也会暂停音乐，恢复后从暂停位置继续。

自定义预设名称用于辨认组合。支持该名称的 GakuMotion 版本可以在相应界面显示预设名；具体识别、动作绑定和物理表现取决于版本及人物组合。

## 场景与道具管理

1. 切换到 **场景管理**或**道具管理**，点击 **扫描场景资源**。
2. 未检测到已知 Motion 服务时，资源控制会自动就绪；使用兼容的 Motion 时，按窗口提示进行资源控制交接。
3. 在左侧选择资源，查看右侧名称和状态；点击 **切换显隐**。受保护、不可操作或未识别到的资源无法切换。
4. 如需恢复，重新选择已隐藏的资源并切换显隐；交还 Motion 控制时插件会尝试恢复它记录的状态。

场景节点按层级展开，隐藏可控制的父节点会影响其子树；名称标注的“推测”仅供参考。场景名称和完整路径能够唯一确定的节点可保存备注。场景页还提供 **选择背景颜色…**、**启用纯色背景**和 **恢复背景**。在 **舞台导入**页选择摄影舞台后，点击 **应用到下次背景载入**；选择保存在配置中，通常要等**下次摄影背景载入**才会生效。部分舞台为实验选项，且摄影舞台替换仅适用于受支持的摄影场景。道具列表仅包含当前扫描规则能识别的对象，不代表游戏中的全部道具。`Prop_Hknesuitcase` 同时控制经身份核验的行李箱网格，并在恢复时分别还原原始状态。

## 自由视角

自由视角已集成在 `GakuActors.dll` 中。连接游戏后在客户端开关相机。W / A / S / D 移动，空格 / Ctrl 升降，方向键转向，Q / E 调整视野，R 重置，F 切换自由、跟随和第一人称模式，V 切换对应子模式。配套 GakuMotion 可在打开自由视角时交出相机控制，并在关闭后接回。

## 与 GakuMotion 一起使用

GakuActors 可以独立管理场景资源；GakuMotion 负责外部动作、镜头等演出功能。想让新增人物使用动作时：

1. 在 GakuActors 中创建人物，并确认其已经出现在场景中。
2. 打开 GakuMotion，刷新或检查场景人物列表。
3. 在 GakuMotion 中选择对应人物并绑定动作；人物识别、名称显示、人数限制和动作物理效果取决于所用版本，可能需要逐项验证。

**Motion 资源控制交接（测试版）：** 使用支持 `gakumotion.visual-handoff` 的配套 GakuMotion 时，可在窗口右上方点击 **启用资源控制**。插件会先请求 Motion 恢复并释放资源，然后自动启用显隐。可点击同一位置的 **交还 Motion 资源控制**；关闭或断开使用过资源控制的管理窗口时也会自动尝试交还。交还前 GakuActors 会先恢复自己修改的资源；恢复失败时会保留控制权并记录警告。

未提供交接接口的旧版 Motion 仍会被保守地阻止与本插件同时控制显隐。摄影背景载入钩子由加载器独占管理；交接时会尝试释放，若被其他插件占用，摄影舞台替换仍可能不可用。交接和具体游戏组合仍需实机验证。配套 Motion 源码改动见 [兼容补丁](compat/gakumotion-visual-handoff.patch)。

## 常见问题

**按钮是灰色的，或窗口提示未进入场景？** 先进入受支持的拍摄 / Live 场景，并等待游戏加载完成。加入人物还需要选中预设、选择参考人物并启用人物加载；部分功能在人物构建中或动作播放时不可用。

**找不到某套服装，或某个人物没有预设？** 先重新读取人物目录。部分人物可能只有单独的身体、脸部、头发资源，没有现成服装预设；可以尝试在人物分类下新建组合。目录是否完整、资源是否已下载及不同组合是否可用，取决于游戏实际数据。

**模型图标没有显示？** 图标来自游戏目录中 `GetThumbAssetName` 的原生记录。游戏内图片未加载时，窗口会尝试从本地 Octo 缓存提取，并校验资源包哈希。未缓存、匹配不唯一或解析失败时显示具体原因；可在游戏中打开对应服装页，再点击 **重试当前图片**。读取本地缓存需要 Python、PyCryptodome 和 UnityPy；发行包将它们放在 `runtime` 中。

**加入后看不到新人物？** 新人物最初与参考人物重叠。等待构建完成后，在“当前场景人物”中选择标有“本插件新增”的人物，设置不同的世界坐标。若仍未出现，请查看窗口状态和日志，确认是否构建失败或资源不可用。

**显隐或背景控制不可用？** 先扫描场景资源并确认资源控制已就绪；受保护节点不能修改。若同时使用动作插件，请等待交接完成；摄影舞台的载入钩子仍可能被其他插件占用。

**如何反馈问题？** 在确认日志不包含不愿公开的内容后，提供游戏版本、GakuActors 与 GakuLoader 版本、是否安装 GakuMotion、所在场景、操作步骤，以及 `GakuLoader/Logs/gakuloader.log` 中相关的 `[GakuActors]` 日志。

普通使用默认关闭开发信息日志。需要排查时，按 [Live 诊断与日志](docs/LIVE_DIAGNOSTICS.md) 中的方法临时开启；警告和错误不受该开关影响。

## 从源码构建

需要 Windows x64、Visual Studio C++ 工具链、Windows SDK、CMake 4、Conan、Rust 和 Cargo。先按 `camera-core/hosted/conanfile.py` 生成 Conan CMake toolchain，然后在项目根目录执行：

```powershell
# 构建含相机功能的游戏插件：输出 build/GakuActors.dll
./build.ps1 -Target Runtime -ConanToolchain <Conan生成的toolchain路径>

# 构建并整理独立窗口及其许可：输出 build/slint-desktop/
./build-desktop.ps1
```

若使用便携式 MSVC 或 Windows SDK，可向 `build.ps1` 传入 `-PortableVisualStudio` 和 `-WindowsSdkRoot`。安装时将桌面程序及依赖放入游戏根目录下的 `GakuActors/`，插件 DLL 放入 `GakuLoader/plugins/`。上述命令只构建，不会自动部署到游戏目录。

`-Cmake` 可指定 CMake 可执行文件，`-CmakeVisualStudio` 可指定 Visual Studio 实例。构建脚本同时将 GPL-3.0 许可证放入输出目录；发行整合版时须附带许可证和对应源码。

桌面资源库后端的源码在 [`resource-backend/`](resource-backend/)，完整 Windows 安装包的组装步骤见 [发布构建说明](release/构建说明.md)。

开发实现和历史验证记录见 [独立窗口说明](docs/NATIVE_DESKTOP.md)、[场景资源迁移记录](docs/SCENE_RESOURCE_MIGRATION.md) 和 [验证记录](docs/VALIDATION.md)；历史记录中的版本与状态不一定代表当前最新构建。

当前 Slint 页面、软件渲染配置、图片缓存限制及实机验收边界见 [Slint 独立窗口](docs/SLINT_DESKTOP.md)。
