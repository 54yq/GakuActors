# GakuActors

独立的 GakuLoader 场景人物管理插件，提供人物目录、头身预设、场景名单和实验性的独立人物加载。不修改 GakuMotion。

当前源码版本为 **`0.2.0-isolated`**。根据 `0.1.4-diagnostics` 的真实日志修正任务返回值：原生 `BuildAsync` 返回 `(bool, ICampusActorController)`，不是索引。新路径使用空闲索引检查、`CreateActor(index, scene)` 和新控制器自己的完整 `BuildAsync`，不执行共享缓存更新或按字符串身份销毁。

**独立加载默认关闭，尚未通过游戏内验收。** 仅在拍摄／Live 场景中手动启用“独立人物加载（实验）”后可提交。启动、主页、更衣室不自动读取目录或创建人物。

## 人物目录与预设

- 在 GakuLoader 中有独立面板和弹窗，默认快捷键为 Ctrl+J。
- 进入支持场景后手动读取 CharacterMaster、CostumeMaster、CostumeHeadMaster；普通服装的身体／脸／头发资源定义随后分帧解析。
- 尝试读取老师、眼镜老师及三类训练员的原生描述，缺少接口时跳过；不猜测未知 NPC 的资源名。
- 人物名称只作分类，允许跨人物选择身体、脸和头发；组合兼容性仍需实测。
- 预设保存在宿主分配的 `Configs/gakuactors/actor_presets.json`，损坏文件保留且禁止继续覆盖。
- 目录和资源定义存在不代表对应资产已下载，也不代表模型已加入场景。

## 独立加载与所有权

1. 用户进入拍摄或 Live，读取目录，在动作插件中停止播放，再显式启用实验加载并选择参考主角色。
2. 保存既有控制器身份、索引、场景、描述和激活／构建／渲染状态；核对分配索引为空，创建后确认返回实例不属于既有集合。
3. 仅将本次新对象设为不激活，再用参考角色的原生构建设置与所选模型描述调用它自己的 BuildAsync。任务期间拒绝再次提交。
4. 通过 IL2CPP 字段接口读取二元组 Item1 和 Item2，验证返回的是已登记的新实例。身体、脸、头发必须与所选描述一致且有原生骨骼记录，整体需要渲染／材质证据和构建成功标志。
5. 验证既有角色集合未改变后，将新角色放到请求时的参考角色位置并激活。只允许移动和移除完整身份仍匹配的本插件人物。

移除核对创建时的既有实例集合、原生管理器、索引、实例 ID、场景和描述 uniqueId。任一项不能确认就不销毁。Unity 的负数实例 ID 和场景句柄是有效身份，不能被当作失败值。

构建失败、归属不明、既有集合改变或超时会锁定本次运行的后续创建；重读目录、重新勾选或场景切换均不清除故障。观察对象缺失时保留任务根和未完成实例记录，不猜测性地销毁。离开场景尝试取消本插件任务，并仅清理身份完整匹配的本插件实例；宿主关闭回调不调用 Unity 销毁。

**这些是代码防护和离线测试，并不保证当前游戏的原生创建／隐藏／构建生命周期已兼容。** 第一次实测需查看新流程的资源、返回控制器、部件和保留既有角色的日志，不能把编译通过当作模型加载成功。

本插件尚不自动复制主角色动作，不扩展 GakuMotion 的人数上限。动作识别、绑定、原生物理及不同头身组合仍需实测。

## 可重复只读诊断

点击“读取游戏目录”同时输出 `[GakuActors] Diagnostic`：接口完整签名与结果字段、现有角色资源和原生部件 boneCount、标准 Unity 蒙皮网格、材质和骨骼引用。同一次运行中可重复采样，无需每次重启。

原生部件骨骼条目数与 Unity 渲染器骨骼引用数分别统计，不作去重人体骨数解释。零个标准 Unity 网格不单独证明 VL 原生模型缺失。不调用人体骨骼查询或手动 InitializeBones。

## 构建与部署

需要 Windows x64、MSVC C++20 和 Windows SDK。

```powershell
./build.ps1 -Target All -PortableVisualStudio '<MSVC 根目录>' -WindowsSdkRoot '<Windows SDK 根目录>'
```

产物为 `build/GakuActors.dll`。构建脚本不部署或控制游戏。安装只在用户退出游戏后替换本插件 DLL，备份旧版并验证其他插件与用户预设未变。当前运行中的 DLL 不热替换。

`preview/scene-actors.html` 使用示例数据，不代表原生模型显示结果。许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，实测证据与验证边界见 [docs/VALIDATION.md](docs/VALIDATION.md)。
