# Live 诊断与日志

普通运行默认关闭 GakuActors、配套 GakuMotion 与配套 GakuLocalify 的信息级开发日志，警告和错误仍然保留。开关按游戏启动时读取，不在每帧检查文件。

调试或开发新功能时，在游戏目录的 `GakuLoader/Configs/` 下创建一个空文件 `gaku-diagnostics.enabled`，然后重启游戏。排查完成后删除该标记，再重启即可关闭。Motion 的 Live 诊断按钮也只有在启用标记后才可使用。

默认关闭的工作包括：人物目录读取时的额外元数据和人物枚举、Motion 的周期性风场/黑边/动画状态报告、自动音频图遍历与代码转储、角色心跳和翻译统计。动画图中服务于 Live 时钟与循环的状态发现、实际动作、相机、音频以及阴影修正继续运行。

2026-11-16 检查时，`GakuLoader/Logs/gakuloader.log` 约 142 MB。对末尾 12 MB 的历史内容抽样，其中 Motion 信息约 9.1 MB、Localify 约 1.3 MB、GakuActors 约 1.1 MB；样本跨多次启动，不代表单次 Live 或当前每秒写入量。日志较多可能增加 I/O 和诊断工作，但仅凭该样本无法确定卡顿的主要原因。

GakuLoader 和其他未修改的插件仍可能记录日志；已有日志不会自动删除或截断。启用开发标记会增加开销，建议只在需要排查时使用。
