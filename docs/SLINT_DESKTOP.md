# Slint 独立窗口

人物、预设、场景人物、场景节点和道具页面使用 Slint 1.19.0。入口是 `desktop-rust/src/slint_main.rs`，声明式界面位于 `slint_ui.rs`。旧 Win32 代码作为模块保留，仅为乐库和原有辅助 CLI 入口服务；资源管理页面不会启动旧 Win32 布局。

## 渲染与占用

- Cargo 关闭 Slint 默认特性，只启用 Winit 与 software renderer；启动时再次明确选择 software，失败时不会回退 GPU 渲染器。
- 不启用 FemtoVG、Skia、wgpu、Qt 或 WebView 渲染后端。Windows 桌面合成仍可能占用 GPU，软件绘制不等于系统显存绝对为零。
- 预设和模型采用按可用宽度自适应的网格，每页最多 24 项；图像与文字裁剪在卡片内。PNG 在后台解码，最大保留 256×256 图像；最多缓存 48 对图片，像素负载上限约 24 MiB，不等于整个进程内存上限。
- IPC 命令通道、图片待办和返回事件都有界；人物位置更新只合并相邻的同人物移动，重置等命令维持顺序。
- 160 ms 的 UI 定时器只读取后台消息，不强制重绘；没有数据变化时不更新控件模型。

## 功能与交互

人物目录、分类搜索、预设图片、预设新建/编辑/命名/删除及撤销、跨人物头身组合、原始身体/脸部/头发组合、参考人物站位和加入场景均复用已有游戏协议。预览图支持点击放大，无官方图时显示占位说明。

场景外可以浏览本地图标目录和上次游戏确认的目录；尚无完整目录缓存时，图标仅按真实图标文件名分类，不能作为已验证模型保存。首次连接游戏并读取目录成功后会缓存目录供后续场景外使用；游戏更新后缓存按资源清单校验。缺少图标索引时后台生成索引，缺少图片时后台使用单线程预缓存本地资源，当前可见图片也可按需读取，不下载资源。

窗口初始物理尺寸受 Windows 工作区约束，较窄窗口使用紧凑导航及详情列。模型详情与长状态信息可滚动；原始部件按真实目录关系唯一匹配时显示对应图片，多重或不明关系不会猜图。

场景人物支持即时坐标提交、位置重置、相对转向和 0–360 度朝向，显隐与移除。重置等待游戏回读确认，不关闭页面。原有人物和新增人物都使用场景内的当前身份；列表刷新时，参考人物按实例 ID 保持选择。

场景页面包含节点筛选、节点显隐、纯色背景及下次摄影舞台选择；道具页面包含筛选、显隐。资源控制继续通过游戏插件自动请求 Motion 交接；自由视角入口继续调用整合版游戏插件。删除、移除会先确认，保存预设会等待快照确认。

## 构建及验收边界

使用支持当前锁定依赖的 Rust stable、MSVC 与 Windows SDK，运行 `build-desktop.ps1`。脚本构建 Release，收集依赖许可并将程序命名为 `GakuActors.Desktop.exe`。本机使用 Rust 1.100.0。

仅做 CLI 编译、依赖树及二进制检查，不启动 GUI、不模拟点击、不运行游戏。布局的实际视觉效果、跨显示器缩放、真实 CPU/显存数值和游戏联动仍需用户实测；编译成功不能替代这些验收。

安装时只更新独立窗口及其许可文件，游戏插件协议不变。窗口包含 Slint GPL-3.0 组件，分发须保留 GPL-3.0、对应源码及依赖声明；锁定版本见 Cargo.lock。

独立窗口可直接启动，等待本机游戏和插件，并在连接及运行时就绪后尝试读取一次人物、服装和头部目录。之后可在“资源设置”中手动更新；失败显示原因，不会持续重试扫描。请求在游戏主线程执行，不加入角色或控制场景。独立连接限制本机当前用户，客户端核对游戏路径与服务端进程 ID。游戏未运行时可浏览已有缓存。

## 场景树、备注和实时定位

场景和道具页面提供资源扫描及 Motion 交接入口。未检测到已知 Motion 服务时资源控制自动就绪；不能证明其他第三方插件没有控制同一对象。场景节点按父子关系展开，隐藏可控制的父节点会影响其子树，人物、相机及其他受保护对象仍按原规则锁定。列表上的“推测”是按名称生成的提示，不改变资源行为。可对场景名称和完整层级路径都能唯一确定的节点保存备注；重名或缺失父节点时不能保存，防止备注关联到错误对象。备注存于游戏的 `GakuLoader/Configs/gakuactors/scene-notes.json`。

人物位置滑块范围为 −256 至 256 米，方向键支持 0.01 米微调；朝向滑块范围为 0–360 度。滑动时发送位置或朝向，重置仍等待游戏回读。纯色背景使用 Windows 取色器及颜色预览；舞台选择独立位于“舞台导入”。

原始身体、脸部及头发只列出游戏目录中已确认的真实模型资源，随分帧扫描更新并缓存；图标本身不代表模型资源已下载或加载。扫描结果和不同场景中的效果需实际运行游戏验收。

人物页顶部显示游戏连接状态，并可点击“手动连接”；连接正常但人物数据库读取失败时，可点击“重试目录”。人物目录与加载设置位于左侧“选择人物”上方；加入场景前选择场景内已有的参考人物。首次窗口尺寸按系统主显示器工作区和缩放比例计算，用户可自行调整。
