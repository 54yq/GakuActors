# 第一版验证记录

版本：`0.1.0-dev`。本记录区分离线结果与未执行的游戏内验收。

## 已执行

- MSVC 14.35、Windows x64、C++20、`/utf-8` 本地编译，生成独立 `GakuActors.dll`。
- 45 项核心检查通过：人物预设字段、非法／冲突组合、特殊人物接口白名单、中文路径读写、编辑与删除、损坏／重复 ID 文件拒绝覆盖、目录匹配、值类型 `runtime_invoke` 的 unbox 边界、异常返回和非本插件人物的移除拒绝。
- 只加载本次编译的 `GakuActors.dll` 进行 C ABI 合成检查：版本／长度／空指针拒绝、失败时输出不变、独立插件标识、生命周期回调、无 actor tick 接管。
- 本地 Chromium 无界面预览：桌面和窄容器分别通过 9 项浏览器交互／布局检查，覆盖新建预设、保存、加入、重叠状态、移除、特殊人物筛选、老师选择和内容宽度。截图已目视检查。预览使用示例数据，不连接游戏。
- 本项目的修改仅提交到独立 `GakuActors` 仓库，没有修改或提交 `source-clock-fix` 源码；构建脚本没有部署步骤；未启动、连接或控制游戏进程。

日志位于 ignored `build/`，不作为游戏内成功证据。

## 原生加载防护

- 仅在可唯一确认的 Photography 场景中尝试创建，且必须有同场景参考角色。
- 创建前核对独立 ID setter、索引、创建、完成观察、取消和释放方法；不以方法名称或参数数量直接冒充完整签名。
- 创建任务使用独立取消源。场景变化时请求取消，等待原生任务结束再释放观察状态。
- 创建完成后检查控制器类型和场景归属，再登记实例。新增世界位置和朝向取请求时的参考角色。
- 移除只使用本插件生成的独立 ID；名单／UI 不持有托管指针。原生对象访问只发生在 Unity 线程。
- 界面需显式启用实验加载；读目录和保存预设不需要启用。

这些是代码边界和合成检查，不能替代下面的实机验收。
